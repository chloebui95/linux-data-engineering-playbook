Linux Data Engineering Playbook

Production Systems Reference & Command Matrix

1. Identity, Users & Permissions IDENTITY
  • whoami / env / pwd -P ➔ User identity, active env vars & physical path.
  • hostname -I / uname -rm / cat /etc/os-release ➔ Host IP, kernel & OS metadata.
  • type <cmd> / which <bin> / ls -ltra ➔ Binary $PATH lookup & time-sorted list.
  • man / tldr / help ➔ Command manuals & concise usage guides.
  • sudo -i / getcap / setcap ➔ Root elevation & granular binary capabilities.
  • adduser / usermod / last ➔ User creation, group membership & login audit.
  • chmod / chown ➔ Modify file permission bits (755) & user/group ownership.
  • apt / dpkg -s / dpkg -S ➔ Package management, status & file ownership.
2. CPU Capacity & System Load CPU
  • uptime ➔ 1, 5, 15 min Load Average (tasks in R+D states).
  • nproc ➔ Print total available logical CPU core count.
  • vmstat 1 5 ➔ Monitor run queue (r) & I/O wait (wa) per sec.
  • top ➔ Interactive process CPU & thread monitor.
  • btop / htop ➔ Terminal resource monitor with CPU graph.
  • mpstat ➔ Multi-processor per-core CPU utilization metrics.
  • taskset -c 0,1 <cmd> ➔ Pin process execution to CPU cores.
Load Rule: If 1-min Load Avg > nproc, tasks queue for CPU!
3. Memory, Swap & Kernel MEMORY
  • free -h ➔ Compare free RAM vs available RAM.
  • VIRT / RES / SHR ➔ Requested virtual, physical RSS & shared RAM.
  • sysctl vm.swappiness ➔ Adjust disk swap out aggression (0-100).
  • sysctl vm.max_map_count ➔ Max memory map limit for JVM/ES.
  • dmesg -T | grep -i oom ➔ Audit kernel OOM-killer kill events.
  • journalctl -k -e ➔ Inspect kernel boot & memory logs.
4. Disk Storage & Inodes DISK
  • df -h ➔ Human-readable disk space utilization by mount.
  • df -i ➔ Inode utilization count (small file exhaustion trap!).
  • du -sh * | sort -hr ➔ Top storage consumer directories.
  • lsblk ➔ Block storage devices, partitions & mount points.
  • truncate -s 0 file.log ➔ Truncate log size without breaking FD.
  • find /path -name '*.log' -mtime +7 ➔ Find files by age/name.
  • locate <file> ➔ Fast indexed path lookup.
  • lsof +L1 ➔ Track space locked by unlinked deleted files.
  • stat ➔ Display detailed file/filesystem metadata & inodes.
  • mount / umount ➔ Attach or detach filesystems & storage devices.
  • iostat ➔ Storage device I/O statistics (tps, read/write MB/s).
5. Process Control & Streams PROCESS
  • ps -eo pid,ppid,stat,cmd ➔ Snapshot active process state.
  • pgrep -a -f <pattern> ➔ Match PIDs with full command string.
  • pkill -f <pattern> ➔ Send signal to matching processes.
  • SIGTERM (15) / SIGKILL (9) ➔ Exit 143 (graceful) vs 137 (kill).
  • nohup <cmd> & / disown ➔ Detach process from terminal session.
  • ulimit / prlimit ➔ View/set user process limits (e.g. nofile).
  • crontab -e / crontab -l ➔ Edit/list automated cron schedules.
  • FD 0 / 1 / 2 ➔ Standard Input (0), Output (1), Error (2).
  • > file 2>&1 & /dev/null ➔ Stream redirection & discard.
6. Network, Sockets & Firewalls NETWORK
  • 0.0.0.0 vs 127.0.0.1 ➔ Public/all interfaces vs loopback.
  • ss -tulpn ➔ Display active listening TCP/UDP sockets with PID.
  • nc -zv <host> <port> ➔ Test TCP socket reachability probe.
  • curl -I <url> ➔ Fetch HTTP response headers & status codes.
  • nmap -p <port> <host> ➔ Port connectivity & security scanner.
  • getent hosts <name> ➔ Name resolution check (/etc/hosts+DNS).
  • ufw status numbered ➔ Display active firewall rules & status.
  • iptables -L ➔ Inspect low-level netfilter firewall tables.
  • ip addr / ip route ➔ Manage network devices, IPs & routing table.
7. Services & Container Logs SERVICES
  • systemctl status <service> ➔ Inspect systemd service status.
  • journalctl -u <service> -f ➔ Tail live service logs.
  • podman / docker logs -f ➔ Follow container application logs.
  • cut -d',' -f1,3 ➔ Extract specified delimited text columns.
  • tee -a logfile.txt ➔ Write to stdout & file simultaneously.
8. Text ETL & Log Pipelines LOGS
  • grep -R -i "ERR" /log ➔ Recursive case-insensitive search.
  • zgrep "ERR" app.log.gz ➔ Search compressed .gz archives directly.
  • head / cat / wc -l ➔ Inspect file top lines, content & total line count.
  • sort -k2 -nr ➔ Sort lines numerically on col 2 descending.
  • uniq -c ➔ Count consecutive duplicate line occurrences.
  • awk -F',' '$3 > 100' ➔ Field-level pattern scanning & processing.
  • sed 's/old/new/g' ➔ Stream editor string replacement.
  • xargs -n 1 -P 4 ➔ Build & execute parallel command lines.
  • lsof -i :port / -p PID ➔ List open files, sockets & process FDs.
  • sysctl -a ➔ Configure runtime kernel parameters dynamically.
9. Archives & DE Safeguards SAFEGUARDS
  • tar -cvzf / tar -xvf -C ➔ Create & extract gzip archives.
  • zstd -d dataset.tar.zst ➔ High-speed DE compression & decompression.
  • rsync -avz --progress ➔ Efficient differential file sync over network.
  • set -euo pipefail ➔ Fail-fast on errors, unset vars & pipe failures.
