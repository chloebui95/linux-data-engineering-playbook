Diagnose full disk partitions, inode limits, directory size hogs, and perform file searching with locate, find, and grep.

📁 The Inode Exhaustion Trap
A disk can report 0 bytes used but still be 100% FULL if all inodes (file metadata slots) are exhausted by millions of tiny log/session files! Always run df -h AND df -i!

📁 Concept 1: Inode Exhaustion vs Block Storage Capacity
Linux filesystems allocate separate metadata slots called Inodes for every file.
• The Inode Trap: A disk with 100GB free space will throw "No space left on device" if 100% of its inodes are consumed by millions of 0-byte micro-logs or session files.
• Rule: Always check both df -h (storage blocks) and df -i (inode metadata slots).
👻 Concept 2: Deleted Handles & Unlinked Open File Descriptors
Deleting a file with rm unlinks the filename from the directory entry, but disk blocks are NOT freed if a process still holds an open file descriptor (FD)!
• Kernel preserves disk blocks until the process closes the FD or process terminates.
• Use lsof +L1 to locate unlinked open files (marked (deleted)) and reclaim space without rebooting.

🔗 Concept 4: Atomic Symlinks (ln -sfn) & stat Metadata
• Zero-Downtime Atomic Symlink Swaps (ln -sfn): Deploying new ML models or dataset pointers safely requires ln -sfn /data/v2 /data/current. The -n (no-dereference) and -f (force) flags ensure the symlink target is updated in 1 atomic OS operation, avoiding broken path references for active readers.
• File Metadata (stat /path): stat inspects exact Inode number, File Descriptor allocation, and timestamp triplets: Access (atime), Modify (mtime), and Change (ctime).

👻 Deleted File Still Consuming Space (Unlinked Open File)

If rm large_log.log was run but df -h still shows 100% full, a running process still holds the open file handle! Run lsof +L1 to find the PID and restart the service.

💥 100% Inodes Full with 0 Bytes Storage Used

Millions of micro-session or cache files in /var/spool or /tmp consume all inode index slots. Run df -i to verify, then purge using find /path -type f -delete.
